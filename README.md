# Книгоград

Интерактивный прототип поиска книг в Воронеже. Статический сайт, без сборки и внешних зависимостей.

Запуск: `python3 -m http.server 8000 --bind 0.0.0.0`. Откройте корневую страницу.

Данные магазинов, цены, наличие и интервалы самовывоза — демонстрационные. Избранное и тестовые брони сохраняются в localStorage. Реальных заказов сайт не отправляет.
